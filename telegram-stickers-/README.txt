СТИКЕРЫ «ПЛЮХ» ДЛЯ TELEGRAM
==============================================

Формат: 512x512, PNG и WEBP с прозрачным фоном,
белая обводка и мягкая тень — как требует Telegram.
Берите любой из двух форматов, WEBP легче.

КАК ЗАГРУЗИТЬ
1. Откройте в Telegram бота @Stickers
2. Команда /newpack, придумайте название набора
3. Отправляйте файлы КАК ФАЙЛ (не как фото!), по одному
4. После каждого файла отправьте эмодзи из списка ниже
5. Команда /publish, затем короткая ссылка для набора
